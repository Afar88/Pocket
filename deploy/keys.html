Pocket Encryption Key Maker

Makes the agent's X25519 key pair in your browser, identical to npm run keygen. Nothing is stored or sent — this page makes no network calls.

Public key (AGENT_ENC_PUBLIC_KEY)

Private key (AGENT_ENC_PRIVATE_KEY)

Keep the private key safe. Put it only in the GitHub secret AGENT_ENC_PRIVATE_KEY (Settings → Secrets and variables → Actions). Never put it in code, docs, or chat. The public key is safe to share — it goes in the web app's environment.
